Proyecto de Desarrollo de aplicaciones multiplataforma (PPP) de Gisela Rodríguez Mayor (curso 2024-2025)

Este proyecto tiene una parte web con HTML, CSS y Bootstrap, y otra parte web con Python, MongoDB y Flask.

La parte web de HTML está realizada en su totalidad con los recursos proporcionados por la web W3Schools. Centraliza las ITV que hay en la isla de Gran Canaria para facilitar el trabajo de búsqueda al usuario.
La parte web de Python está realizada casi en su totalidad por un vídeo de Youtube, el cuál me dió la estructura completa (solo tuve que cambiar unos puntos y añadir una página para guardar los usuarios). Guarda los datos de los vehículos que inspeccione la persona encargada de revisar los coches en la ITV, facilitándole de igual forma el trabajo.

Durante unas semanas he estado viendo vídeos y practicando para poder comprender cómo funciona Python y MongoDB.
